Sección 1: Introducción a HTML5

HTML5 es la última versión del estándar de lenguaje de marcado utilizado para estructurar páginas web. Introdujo elementos semánticos que mejoran la accesibilidad y el posicionamiento en motores de búsqueda (SEO), así como soporte nativo para audio y video sin necesidad de complementos externos.

Las etiquetas semánticas como <header>, <nav>, <article> y <footer> permiten definir la estructura del documento con mayor claridad para los navegadores y lectores de pantalla.

Sección 2: Hoja de Estilos CSS3

CSS3 permite separar la estructura del contenido del diseño visual. Gracias a CSS3 es posible aplicar reglas de estilo complejas, transiciones, animaciones y esquemas de diseño avanzados como Flexbox y CSS Grid.

Un diseño adaptativo (Responsive Web Design) garantiza que las páginas se visualicen correctamente en una amplia variedad de dispositivos, desde pantallas de escritorio hasta smartphones.
